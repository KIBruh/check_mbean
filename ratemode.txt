Then the rate mode or counter mode:

The plugin needs a state file to keep track of the rate-interval.
If the state-file is empty or there was a counter reset (value smaller than the last) the plugin should ignore the state file.
The rate calculation should work as follows: if state file is ignored, make two measurements of the counter that are --min-rate-interval seconds apart.
Save the measurements in the statefile, the statefile is also specified on the command line.
save all measurements in the statefile that are newer than three times --mean-rate-interval.
calculate all rates in "per minute".
if the statefile is used the rate is calculated with the measurement that is nearest to the point (now - mean-rate-interval), but not older than rate-window-multiplier * mean-rate-interval in which case the state-file is ignored again.
The statefile must not contain any data older than mean-rate-interval * ( rate-window-multiplier + 2)
